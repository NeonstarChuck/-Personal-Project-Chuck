# Personal Project-Chuck

## Welcome to my game called "Animal Rescue"

It's a game based of saving animals that spawns in a small area and you have to protect them from monsters like slimes that tries to eat them up.
To save the animal the player has to capture the animals and bring them to a so called "Safe Zone" where they will be safe from the slimes!

This game is inspired by games like Slime Rancher, but this time the slimes are the enemies! 

# Devolopment
The development of this game was honestly not so good from the developer(me) I had 5 days to complete the game but I only used like 3 days because of laziness (I will admit that), so I had to scratch some ideas to finish the game before deadline.

I had ideas that the player was supposed to also kill the monsters by switch weapons but what I learned from the lessons is that we should focus on the very basic so is atleast playable and I also didnt have super much time.
So I decided to scratch that idea and have the player to only save the animals instead, while this idea was scratched the main purpose of this game was to have enemies that follows the animals around and tries to eat them.
This was much harder then I expected, I thought scripts like transform the enemy to objects with "tag" should be easy, but for some reason I couldn't make it happen LLM couldnt help with that or YT. But I found an alternative solution is to use Navmesh, I had never heard of it til I found it out in YT, and thats where the rabbit hole began, endless research watching tutorials, trying it out in unity, but a lot of failure. Til I found out that the versions I watched was old so I had to look it up in some unity forums and thats where I found about some stuff. I got help from LLM + some newer videos about Navmesh and played around with it. And boom, it worked kind of? After finishing the game, the funniest thing was fixing the navmesh for the enemies, it was fun that you could make mazes with different type of bodies for the enemies, some could go trough smaller spaces, some couldn't, that was a highlight in my experience. 

So game mechanic > UI for this time of project. But I did do some okay basic stuff to my UI with the extened deadline, so it's not utterly awful, I hope?

I think that's enough of yapping. I hope you enjoy the game :D.
